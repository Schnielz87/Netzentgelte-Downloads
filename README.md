# Strom-Netzentgelte – Downloads

Strom-Netzentgelte (SLP, Niederspannung ohne Leistungsmessung, netto) für 11 Netzbetreiber, je Jahr.

**Excel herunterladen:** [Netzentgelte_Strom.xlsx](https://github.com/Schnielz87/netzentgelte-downloads/raw/main/Netzentgelte_Strom.xlsx)

**Ansicht im Browser:** https://claude.ai/artifact/838cFukJgfQWydkKUeBzVB

- `Netzentgelte_Strom.xlsx` – Reiter 2026 (Vorlage) und je ein Reiter pro Jahr ab 2027
- `daten.json` – dieselben Werte maschinenlesbar, mit Quellen (PDF-Links der Netzbetreiber)
- `werkzeug/` – Skript, das die Excel aus `daten.json` erzeugt

Die Werte werden von Oktober bis Januar wöchentlich (montags) aus den offiziellen Preisblättern der Netzbetreiber neu recherchiert.
Vorläufige Netzentgelte vor Abrechnung auf endgültige Fassungen prüfen. Gelb markierte Werte sind offen oder in ihrer Gültigkeit fraglich.
